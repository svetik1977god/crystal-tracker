# 💎 Кристалл — трекер-напоминалка

Красивый трекер задач и напоминаний в стиле «розового хрусталя» — офлайн-приложение (PWA) на чистом HTML/CSS/JS, без фреймворков и без сервера. Все данные живут в браузере пользователя.

## ✨ Возможности

- **Задачи**: создание/редактирование/удаление, дата + время, заметки, приоритет, отметка «выполнено» (4 стиля завершения: зачёркивание / затухание / скрывать / блёстки)
- **Повторы и продление**: ежедневно, еженедельно, ежемесячно, свой интервал; отложить (snooze) на 10 мин / 1 ч / 1 день / своё время
- **Автоперенос просроченных** дел на сегодня
- **Вложения**: документы и фото внутри задачи (IndexedDB)
- **Календарь** с количеством задач по датам и месяцам
- **Умный поиск** по словам + служебные запросы («важно», «сегодня», «просрочено»)
- **Напоминания**: баннер, панель уведомлений, системные уведомления, звук (3 встроенные мелодии + свои аудиофайлы), вибрация, вспышка
- **Профиль**: имя и аватар
- **Категории** задач с цветными метками
- **Оформление**: 4 темы (Кристалл / Ночь / Сакура / Хром) на основе фирменного фото-коллажа, акцентный цвет, 3 стиля интерфейса (стекло / плотный / минимализм), прозрачность панелей, анимации переходов, выбор лого
- **Данные**: экспорт/импорт резервной копии (включая вложения и настройки), чистка кэша, полный сброс
- **PRO-раздел** с PIN-замком владельца (SHA-256): функции можно помечать «только PRO» — задел для продающей версии
- **PWA**: устанавливается на телефон как приложение, работает офлайн

## 🚀 Запуск

Приложение статическое — достаточно любого http-сервера:

```bash
# вариант 1
python -m http.server 8000
# → открыть http://localhost:8000

# вариант 2
npx serve
```

Для полного функционала (сервис-воркер, уведомления, установка на телефон) открывайте по `http://` или `https://` — не как локальный файл.

### Демо одним файлом

```bash
python tools/build_demo.py   # → dist/Crystal-demo.html
```

Собирает всё приложение (стили, код, фото, иконки) в один HTML-файл — удобно пересылать для теста.

### Папка для хостинга

```bash
python tools/mkdeploy.py   # → deploy/ (чистая копия для Netlify / GitHub Pages / любого хостинга)
```

## 📁 Структура

```
index.html            – вход, CSP, подключение env/config.js
manifest.webmanifest  – PWA-манифест
sw.js                 – Service Worker (precache + offline)
css/styles.css        – темы, стеклянный дизайн «Кристалл MAX»
js/
  app.js              – оболочка: роутер, модалки, тосты, панель уведомлений
  views.js            – экраны (задачи, календарь, настройки, PRO)
  store.js            – настройки и задачи (localStorage), экспорт/импорт
  db.js               – IndexedDB (вложения, аватар, звуки)
  notify.js           – движок напоминаний, звуки (WebAudio), вибро, вспышка
  i18n.js             – локализация ru/en
assets/
  collage/            – 9 отдельных фото фирменного коллажа (по одной на тему)
  icon-*.png          – иконки приложения в стиле коллажа
env/                  – приватные настройки (env/config.js — в git не попадает)
tools/                – скрипты сборки (демо, деплой, нарезка коллажа, иконки)
```

## 🔒 Приватность и безопасность

- Нет аналитики, нет внешних запросов — всё локально в браузере пользователя
- CSP-заголовок, экранирование всех пользовательских данных в HTML
- PIN владельца хранится как SHA-256-хэш с солью
