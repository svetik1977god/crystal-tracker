# Проект: Трекер-напоминалка (Копия из Кими)

## История
Приложение создавалось по ТЗ в Kimi (лимит исчерпан), затем работа продолжена в OpenCode.
Этот файл — сохранённый ТЗ и статус проекта на 10.11.2026.

## ТЗ (оригинал от заказчицы)
Мне нужно создать приложение трекер напоминалку. Должна быть адаптирована под айфоны, андроиды, смартфоны, ПК. Для темы я в папку вложила фото. Фото — это коллаж из нескольких рисунков для темы/дизайна приложения. Можно даже кнопки сделать из каких-то элементов из фото. Чтобы можно было добавлять напоминания с повторами, с продлением. Чтобы можно было ставить приоритетность и не приоритетность. Чтобы были оповещения, чтобы можно было ставить отметки «завершено» или еще какие-либо функции. Заметки какие-либо. Чтобы можно было корректировать. Чтобы можно было внутри создать папку для вложения док-тов или фото. Чтобы можно было отдельно открыть календарь и увидеть кол-во заметок в датах по месяцам. Чтобы были настройки профиля. Был поиск умный по словам. Настройки языка, формат времени, цветное обозначение. Можно добавить звук (напишешь, что для этого надо сделать). Автоперенос дел, установить дело с указанием времени, удаление дел. Чтобы можно было чистить кэш. Чтобы была вставлена обратная связь. Была ссылка чтобы поделиться приложением. Была отдельная часть для про версии (на будущее для продажи) и только я смогу туда добавить или перенести функции приложения. Чтобы были настройки уведомлений: напоминание, уведомления, сигнал, без звука, если возможно. То добавить вибро или просто вспышку, панель уведомлений. В настройках дизайна: темы, цвет, стиль, значки, цвет иконки, главный экран, листание страниц, если выполнено, то зачеркивание или еще что-то интересное, шкала прозрачности виджета.

## Структура проекта
- `index.html`, `manifest.webmanifest`, `sw.js` — PWA (CSP-защита, `env/config.js` подключён)
- `assets/` — иконки (сгенерированные в стиле коллажа: 192/512/maskable/1024), фото-коллаж
- `assets/collage/1..9-*.jpg` — **9 отдельных фото из коллажа** (robot, flowers, butterfly, sphere, eye, hummingbird, path, chameleon, skull) — используются по темам
- `env/config.js` — личные настройки (e-mail обратной связи), не для git; шаблон — `env/config.example.js`
- `css/styles.css` — стили (темы Кристалл/night/sakura/chrome на отдельных фото)
- `js/app.js`, `db.js` (IndexedDB), `i18n.js` (ru/en), `notify.js` (уведомления/звуки/вибро/вспышка), `store.js`, `views.js`
- PRO-раздел с PIN-замком (хэш SHA-256)

## Статус (проверено Node, синтаксис чист)
✅ Готово: адаптив, PWA, тема «Кристалл», 4 темы на отдельных фото коллажа, задачи, вложения, календарь, поиск, уведомления, настройки, «поделиться», обратная связь, PRO-раздел с PIN (SHA-256 + миграция старого PIN).

## Безопасность (10.11.2026)
- PIN владельца: SHA-256 с солью (раньше — слабый djb2, старые PIN мигрируют автоматически при первом входе)
- CSP-заголовок в `index.html` (script-src 'self' и др.)
- Приватные данные вынесены в `env/config.js` (исключён из git)
- Проверен XSS: все пользовательские данные экранируются `esc()` перед innerHTML
